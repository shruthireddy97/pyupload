# Knowledge-Based Voice-to-Text Input Conversion (Digital Apprentice)

## Project Overview

This project is an AI-powered knowledge management system that converts spoken conversations into structured text and enables semantic search using Retrieval-Augmented Generation (RAG). The application is designed to capture domain knowledge from voice recordings and documents, generate embeddings, store them in PostgreSQL with pgvector, and retrieve relevant information using Large Language Models through AWS Bedrock.

The system consists of a React frontend and a FastAPI backend, providing an intuitive interface for uploading documents, processing knowledge, and querying stored information.

---

## Features

- User Authentication
- Voice-to-Text Processing
- Document Upload (PDF, DOCX)
- AI-Based Knowledge Extraction
- Semantic Search using Vector Embeddings
- PostgreSQL pgvector Integration
- AWS Bedrock LLM Integration
- FastAPI REST APIs
- React User Interface

## Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/yourrepository.git

cd yourrepository
```

### Backend Setup

```bash
cd be

python -m venv venv

source venv/bin/activate
```

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

### Frontend Setup

```bash
cd frontend-main

npm install
```

---

## Environment Variables

Create a `.env` file inside the backend folder.

Example:

```text
AWS_ACCESS_KEY=
AWS_SECRET_ACCESS_KEY=
AWS_REGION=
POSTGRES_DB=
POSTGRES_USER=
POSTGRES_PASSWORD=
POSTGRES_HOST=
POSTGRES_PORT=
```

**Do not commit actual credentials to GitHub.**
